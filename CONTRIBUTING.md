# Contributing

Thanks for helping out with Darkmatter.

- **Found a bug in this port?** Open an issue here with a screenshot.
- **Want to fix it?** Pull requests are welcome. Use only colors from the
  [palette](https://github.com/darkmattertheme/darkmatter#palette), and write
  commit messages in the
  [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) style,
  for example `fix: cursor color in insert mode`.
- **Want to make a port for another app?** Read the
  [contributing guide](https://github.com/darkmattertheme/darkmatter/blob/main/CONTRIBUTING.md)
  in the core repo. It covers requesting, building, reviewing and listing ports.
